# Measuring handwriting accuracy (private, local)

The system deliberately does **not** promise an accuracy percentage. Before bulk processing, benchmark a sample of 30–50 representative forms with different writers, lighting and camera angles.

1. Configure a reference image, calibrate every field, test image alignment, and upload a pilot batch.
2. In Excel or LibreOffice **on your own computer**, open `examples/ground_truth_template.csv` and enter the order IDs with the **correct values transcribed by a person**. Empty cells are excluded from scoring. Each order ID must be unique. You can use the review interface to find order IDs. Keep this CSV private and do not commit it to GitHub.
3. Copy this local file into the private `data/` directory on the VPS under `data/ground_truth.csv`. The database and image files must stay off GitHub.
4. On the VPS, from the project folder, run:

```bash
sudo docker compose exec -T api python -m app.benchmark /data/ground_truth.csv
```

This prints aggregate field-level exact-match rates, character-error rates and complete-order exact-match rate. It uses `raw_text` generated by the OCR model, **not** your later manual corrections. It prints no names, phone numbers, or other raw reference values. The report cannot guarantee performance outside the tested sample. Checkbox comparisons require separate manual inspection because automatic detection remains heuristic.

Do not treat a successful alignment test as proof that handwriting can be read accurately. Checking the aligned rectangles and reviewing pilot extractions are still necessary.
